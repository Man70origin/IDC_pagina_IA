Modelos CNN Utilizados

🏗️

ResNet (Residual Network)

Red neuronal residual profunda que utiliza conexiones de salto para mitigar el problema del gradiente evanecente. Excelente para capturar patrones complejos en imágenes histopatológicas.

📱

MobileNet

Arquitectura ligera y eficiente optimizada para dispositivos con recursos limitados. Utiliza convoluciones separables para reducir parámetros manteniendo alta precisión.

🧠

CNN (Convolutional Neural Network)

Red convolucional personalizada entrenada específicamente para detección de IDC. Combina capas convolucionales para extraer características distintivas de imágenes.

⚙️

Votación por Ensamblaje

Los tres modelos realizan predicciones independientes combinadas mediante votación ponderada (45% ResNet, 45% CNN, 10% MobileNet) para máxima confiabilidad.
